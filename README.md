# Путь — Telegram mini app

Один паспорт, документы трёх поколений: «Я», «Мама», «Дед». Приложение показывает, куда ехать, что заказать, что уже получено и когда подавать общий комплект.

**[Публикация по шагам → docs/START-RU.md](docs/START-RU.md)**

- `web/mini.html` — приложение, которое открывается кнопкой «Открыть Путь» в боте.
- `web/app.js`, `web/roadmap.js`, `web/people-icons.js` — интерфейс «Пути»: обзор, документы, поездки, план.
- `web/cloud.js` — связь с сервером: вход через подпись Telegram, загрузка и сохранение дела.
- `web/*.css`, `web/assets/fonts/` — оформление и шрифт Golos Text (лицензия OFL в папке шрифтов).
- `supabase/` — сервер: проверка входа Telegram, хранение дела, ИИ-поиск учреждений, бот.
- `.github/workflows/deploy.yml` — автоматическая публикация после `git push`.

Обновление — обычный push. GitHub Actions прогоняет тесты, обновляет базу и сервер в Supabase, публикует сайт на GitHub Pages и ставит кнопку **Открыть Путь** в бот.

Данные: всё дело хранится одним JSON (`kinpass_state.put_state`) у каждого Telegram-пользователя. Прежние данные Kinpass (`documents`, `institutions`) не удаляются; при первом открытии «Путь» переносит их в свою модель.
