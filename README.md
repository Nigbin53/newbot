# Kinpass — Telegram Mini App

Комплект для запуска приложения документов через Telegram, GitHub Pages и Supabase. Визуальный стиль — монохромный clear glass.

**[Публикация по шагам → docs/START-RU.md](docs/START-RU.md)**

- `web/mini.html` — приложение, которое открывается из меню Telegram-бота.
- `web/index.html` — дизайн-студия с демо-данными.
- `supabase/` — сервер: проверка входа Telegram и личное хранилище документов.
- `.github/workflows/deploy.yml` — автоматическая публикация.

Обновление — обычный push:

```sh
git add .
git commit -m "Что изменил"
git push
```

После push GitHub Actions прогоняет тесты, обновляет базу и сервер в Supabase, публикует сайт на GitHub Pages и ставит кнопку **Открыть Kinpass** в бот. Токены хранятся в секретах репозитория.

Приложение: `https://OWNER.github.io/REPO/mini.html`.

В облачном приложении каждый Telegram-пользователь получает своё пустое дело. Разделы «Я», «Мама», «Дедушка» принадлежат одному владельцу дела; приглашения родственников в общий аккаунт пока не реализованы.
